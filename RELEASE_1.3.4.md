# Brandweerrooster API v1.3.4

## Release notes

This release contains final validation fixes for public distribution.

### Fixed

- Corrected `manifest.json` key ordering for Home Assistant Hassfest validation.
- Declared the integration as config-entry-only using Home Assistant's `config_entry_only_config_schema`.
- Kept all functionality from v1.3.3 unchanged.
- Updated the integration version to `1.3.4`.

### Compatibility

Existing Brandweerrooster API configuration entries remain compatible. No user configuration changes are required.
